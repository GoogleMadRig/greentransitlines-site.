Greentransitlines | Integrated Passenger Rail InterfaceProject OverviewGreentransitlines is a high-fidelity front-end web interface designed as part of a multi-phase business plan for high-speed and regional rail restoration. This project serves as a "Digital Gateway" for passengers, demonstrating how complex transportation logistics can be translated into a seamless, user-centric web experience.For recruiters, this project highlights a multidisciplinary approach to Systems Architecture, UI/UX Design, and Vanilla JavaScript development.User Workflow & Functional Specifications1. Dynamic Booking EngineThe core "Mission-Critical" component of the site is the interactive booking widget.Autocomplete Data Protocol: Utilizes a pre-cached array of 50+ Florida rail stations. As a user types, a custom JavaScript listener filters the array to provide low-latency station suggestions.State Management: The "One-Way" vs. "Round-Trip" toggle dynamically updates the DOM to show or hide return-date inputs, optimizing the interface for the specific user workload.Station Swap Logic: Includes a "Swap" function to instantly re-route departure and arrival inputs, ensuring a frictionless user experience.2. Multi-Tier Service ArchitectureThe interface distinguishes between four distinct service "Availability Zones":Express (greenbulletlines): High-speed connectivity (up to 220 mph).Regional Connector: A limited-stop "backbone" service.Commuter (Tri-Rail & SunRail 2.0): High-frequency local transit.3. Data-Rich Modals (Technical Documentation)Rather than cluttering the primary UI, detailed route and fleet specifications are housed in high-performance modals.Route Maps: Provides detailed station listings for the South Florida and Central Florida Rail Corridors (SFRC and CFRC).Fleet Tech Specs: Documents the "Hardware" layer of the project, detailing the use of Hitachi and Siemens trainsets for specific operational missions.Technical Stack & ImplementationFrontend Architecture: Built with semantic HTML5 and CSS3, utilizing custom CSS variables for consistent branding and thematic design.Logic Layer: Developed entirely in Vanilla JavaScript to maintain high performance and avoid the overhead of heavy frameworks. Includes event delegation for modals and custom form validation.Responsive Deployment: Employs a Mobile-First approach using CSS Flexbox and Grid, ensuring the "Booking" experience remains deterministic across mobile, tablet, and desktop viewports.Design Philosophy: Incorporates "Amtrak Blue" and "Greentransitlines Green" to build a professional, trustworthy aesthetic consistent with North American rail standards.Recruiter Insights: Why This MattersThis project is a direct application of the skills listed in my professional profile:Systems Thinking: Translates the logistical complexities of the Kinetra Transit Lines business plan into a structured digital format.  Workflow Design: Applies digital workflow principles across planning, data collection (the booking form), and reporting phases.  Documentation: Every aspect of the UI corresponds to functional specifications documented in the broader 37-page technical research and business planning artifacts.
